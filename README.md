# Smart Emergency Response Center – Mini Operating System

## Project Overview

The Smart Emergency Response Center is a C-based Mini Operating System developed as an academic project at Copperbelt University. It features a graphical user interface built with GTK3 and demonstrates key operating system concepts through process management, CPU scheduling and memory management.

## Technologies Used
- C Programming Language
- GTK3
- Linux/Windows development tools (depending on the build environment)

## Key Features

- **Process Management:** Create and manage processes using Process Control Blocks (PCBs) and process state transitions.
- **CPU Scheduling:** Implements First Come First Served (FCFS), Shortest Job First (SJF) and Priority Scheduling.
- **Memory Management:** Implements the First Fit memory allocation algorithm, including allocation, deallocation, block splitting and coalescing.
- **Graphical User Interface:** Allows users to interact with the system and run simulations.
- **Event Logging:** Records system activities with timestamps in a log file.

## Project Structure

The repository contains the C source files, GTK-related resources, project documentation, log file and a compiled executable.

## Running the Application

Download the repository and extract all files into one folder. Locate and run the compiled executable.

**Note:** The application may require the appropriate GTK3 runtime libraries and other dependencies.
